# 🚗 Car Rental System

A front-end based Car Rental System developed using **HTML**, **CSS**, and **JavaScript**. The platform supports multiple user roles and simulates the process of booking and managing cars, trips, drivers, and invoices.

## 🔍 Project Overview

This project is designed to allow users to book cars (with or without drivers), list their own vehicles for rental, and manage platform operations. It includes four distinct roles with unique dashboards:

### 👥 User Roles

- **Customer**
  - Browse and book available cars
  - Option to book a car with or without a driver
  - Download invoices (generated by the manager)
  - View booking history

- **Driver**
  - View assigned trips
  - Track upcoming trips
  - Monitor earnings/salary

- **Car Owner**
  - List their vehicles for rent
  - Track earnings from rentals
  - View bookings on owned cars

- **Manager**
  - Approve or reject car listings
  - Assign drivers to bookings
  - Generate and manage invoices
  - Monitor overall system activity

## 🛠️ Technologies Used

- **HTML** – Page structure and layout
- **CSS** – Styling and responsive design
- **JavaScript** – Client-side logic and dynamic interactions

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Navigate to your role page (Customer, Driver, Owner, Manager).
4. Interact with the platform – booking, tracking, or managing data.

## 📌 Note

This is a front-end simulation project — no backend or database is connected. Data is managed using in-memory JavaScript arrays and objects.
